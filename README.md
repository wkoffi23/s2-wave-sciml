# s2-wave-sciml
Simulation numérique et Scientific Machine Learning (SciML) pour la propagation d'ondes linéaires et non-linéaires sur la sphère $\mathbb{S}^2$ en milieu inhomogène. Inclut un solveur EDP vectorisé et une étude comparative de deux Neural Operators auto-régressifs (SFNO et GNO) sur plusieurs pas de temps.
